# Music Loader

Приложение для загрузки аудио из YouTube-плейлистов и создания случайного Mega Mix.

## Запуск

1. Установите зависимость: `pip install customtkinter`.
2. Убедитесь, что в корне находится `yt-dlp.exe`.
3. Запустите `python mega_mix_music_loader.py`.

Плейлисты находятся в `config.json`, музыка — в `Music/`. Подробнее — в `PROJECT.md`.

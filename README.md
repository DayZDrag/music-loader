# Music Loader

Приложение для загрузки аудио из YouTube-плейлистов и создания случайного Mega Mix.

## Зависимости

Приложение зависит не только от Python-пакетов, но и от локальных программ в формате `.exe`. Они намеренно не добавляются в Git-репозиторий, поэтому после клонирования их нужно скачать и положить в корень проекта.

| Компонент | Назначение | Ожидаемое расположение |
| --- | --- | --- |
| Python 3 | Запуск приложения | В системе / виртуальном окружении |
| `customtkinter` | Графический интерфейс | Установить через `pip` |
| `yt-dlp.exe` | Получение плейлистов и скачивание аудио | `yt-dlp.exe` |
| FFmpeg | Конвертация аудио в MP3, метаданные и обложки | `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe` или папка `ffmpeg-*/` |
| Deno | JavaScript-рантайм для yt-dlp | `deno.exe` и `deno-x86_64-pc-windows-msvc/` |
| Firefox | Чтение cookies при запросах к YouTube | Установленный Firefox с нужным профилем |

## Запуск

1. Установите Python 3 и пакет: `pip install customtkinter`.
2. Положите `yt-dlp.exe`, FFmpeg и Deno в указанные выше места.
3. Убедитесь, что Firefox установлен, если хотите использовать cookies браузера.
4. Запустите `python mega_mix_music_loader.py`.

Плейлисты находятся в `config.json`, музыка — в `Music/`. Подробнее — в `PROJECT.md`.

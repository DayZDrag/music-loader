# Music Loader

Графическое приложение на Python и CustomTkinter для управления YouTube-плейлистами, скачивания аудио через yt-dlp и создания случайного Mega Mix из локальной MP3-коллекции.

## Структура

- `mega_mix_music_loader.py` — точка входа и UI.
- `music_loader/paths.py` — пути к данным и утилитам.
- `music_loader/config.py` — загрузка и сохранение `config.json`.
- `music_loader/theme.py` — палитра интерфейса.
- `music_loader/dashboard.py` — построение основной неоновой панели интерфейса.
- `download.bat` — альтернативное консольное обновление плейлистов.

Папка `Music/`, список уже скачанных файлов и локальные исполняемые файлы не хранятся в Git.

Во время загрузки нижняя консоль остаётся видимой и показывает вывод yt-dlp. Над ней отображается общий прогресс текущей очереди.
